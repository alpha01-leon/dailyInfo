## 每日文档格式

`src/YYYY-MM-DD.md` 统一按以下顺序编排：

1. 5 分钟摘要
2. 热点聚合与中文媒体
3. 官方发布
4. 论文、模型与开源趋势
5. 行业、安全与深度分析
6. 综合观察
7. 来源访问与口径说明

重点文章使用四级标题并附原文链接；同一来源的论文榜单、模型趋势等批量条目使用列表，文章名称仍附原文链接；来源栏目使用三级标题并链接到来源首页；没有单篇链接的内容只记录为首页观察。
